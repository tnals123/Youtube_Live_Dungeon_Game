🏰 던전 레이드 (Dungeon Raid)

게임 소개 및 설명 문서
유튜브 라이브 방송 시청자들이 채팅창에 명령어를 입력해 실시간으로 파티를 이루고, 함께 몬스터를 쓰러뜨리며 던전을 공략하는 시청자 참여형 인터랙티브 게임입니다.

게임 소개

"던전 레이드"는 별도의 게임 클라이언트 설치나 컨트롤러 없이, 오직 유튜브 라이브 채팅만으로 진행되는 시청자 참여형 게임입니다. 시청자는 화면 속 캐릭터를 직접 조작하는 대신, 채팅창에 명령어를 입력하는 것만으로 게임 세계에 실시간으로 개입합니다.

🎮
채팅으로 캐릭터 조작 유튜브 라이브 채팅창에 명령어를 입력함으로써 본인의 캐릭터를 움직이고 전투에 참여합니다.
🎲
직업과 등급 랜덤 배정 /참가를 입력하면 전사·궁수·마법사·힐러 중 하나의 직업과, 일반부터 전설까지 5단계 중 하나의 등급을 무작위로 부여받습니다. 등급이 높을수록 전투력이 높습니다.
🗳️
탐험 이벤트 투표 갈림길이나 상자 같은 이벤트가 나오면 채팅 다수결로 선택지를 정합니다. 정답을 고르면 안전하게 지나가고, 오답을 고르면 함정에 걸려 피해를 입습니다.
⚡
보스 패턴 대응 보스가 패턴을 예고하면 제한시간 안에 자신의 직업에 맞는 방어 명령어를 입력해야 합니다. 충분히 모이면 피해를 막고, 부족하면 파티 전체가 피해를 입습니다.
실제 방송에서는 스트리머 한 명과 시청자 여러 명이 채팅으로 함께 던전을 진행합니다.

게임 방법

목표

파티(참여한 시청자 전원)가 힘을 합쳐 던전의 모든 층을 순서대로 클리어하고, 최종 보스까지 무찔러 던전을 정복하는 것입니다.

조작 (실제 라이브 버전 기준)

모든 조작은 유튜브 라이브 채팅창에 아래 명령어를 입력하는 것으로 이루어집니다.

명령어설명
/참가파티에 합류 (직업·등급 무작위 배정)
/왼쪽, /오른쪽 등탐험 이벤트(갈림길 등)에서 선택지 투표
/강타 (전사) · /저격 (궁수) · /파이어볼 (마법사) · /정화 (힐러)직업별 공격 명령어 - 반복 입력할수록 자주 공격
/힐힐러 전용 파티 회복 명령어
/방어 (전사) · /퇴격 (궁수) · /역산 (마법사)보스 패턴 예고 시 파훼 게이지를 채우는 방어 명령어

직업 · 등급 시스템

직업공격 스킬패턴 방어 스킬
⚔️ 전사강타방어
🏹 궁수저격퇴격
🔮 마법사파이어볼역산
💚 힐러정화 (공격) / 힐 (회복)-

등급은 일반 → 고급 → 희귀 → 영웅 → 전설 순으로 희귀할수록 전투력 배율이 크게 올라갑니다 (일반 대비 전설은 최대 100배). 등급이 높은 소수 인원이 파티 전체를 캐리하는 것도 가능해, 누가 어떤 등급을 뽑는지도 매 방송마다 관전 포인트가 됩니다.

진행 흐름

1
로비 - 일정 시간 동안 /참가로 시청자를 모집합니다.
2
던전 입장 브리핑 - 파티 구성, 총 전투력, MVP 후보를 보여줍니다.
3
탐험 층 - 갈림길·상자 등 이벤트가 등장하면 채팅 다수결로 선택 → 정답/오답에 따라 파티 체력이 변합니다.
4
전투 층 - 몬스터가 등장하면 직업별 명령어로 자동 공격합니다. 보스는 주기적으로 패턴을 예고하며, 제한시간 안에 파훼 게이지를 채워야 합니다.
5
결과 - 던전 정복 또는 파티 전멸 결과 화면이 표시된 뒤, 자동으로 로비로 돌아가 다음 라운드 모집을 시작합니다.

종료 조건

  • 승리: 마지막 층(최종 보스)까지 클리어하면 "던전 정복" 결과 화면이 표시됩니다.
  • 패배: 파티 전체 체력이 0이 되면 "파티 전멸" 결과 화면이 표시되고, 자동으로 로비로 리셋되어 다시 도전할 수 있습니다.

실행 방법 (심사용 플레이 안내)

심사자는 별도 설치 없이 아래 링크에 접속하면 바로 플레이할 수 있는 1인용 솔로 데모를 준비했습니다. 실제 게임은 유튜브 라이브 방송과 다수의 시청자가 있어야 진행되는 구조이기 때문에, 심사자가 혼자서도 게임의 핵심 진행(로비 → 던전 입장 → 탐험 갈림길 → 전투 → 패턴 보스전 → 클리어)을 처음부터 끝까지 체험할 수 있도록 다른 시청자들이 자동으로 채팅에 참여하는 데모 버전을 별도로 만들었습니다. 화면 오른쪽에는 실제 유튜브 라이브 채팅을 재현한 로그가 함께 표시되어, 실제 방송에서 어떤 식으로 진행되는지도 함께 확인하실 수 있습니다.

  1. 아래 플레이 링크 접속 (PC/모바일 브라우저 모두 지원, 설치 불필요)
  2. 로비 화면에서 다른 시청자(봇)들이 자동으로 참가하는 동안, "✋ 참가하기" 버튼을 클릭
  3. 1층 몬스터 "플러그" 전투 - 화면 하단 스킬 버튼으로 공격
  4. 2층 갈림길에서 ⬅️ 왼쪽 / ➡️ 오른쪽 중 선택
  5. 3층 미니보스 "스크라벤" 전투 - 평소엔 공격 버튼, 패턴 예고가 뜨면 제한시간 안에 방어 버튼 클릭
  6. 던전 클리어 후 "🔁 다시 플레이"로 반복 체험 가능

참고: 실제 라이브 서비스는 스트리머가 별도의 백엔드 서버(Flask + Socket.IO)를 구동하고, OBS 브라우저 소스로 게임 화면을 방송에 송출하며, 유튜브 라이브 채팅 API로 시청자 명령어를 실시간으로 수집·처리하는 구조로 동작합니다. 이 백엔드를 포함한 전체 소스 코드는 GitHub 저장소에 공개되어 있습니다.
